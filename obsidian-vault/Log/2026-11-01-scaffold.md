# 2026-11-01 — Scaffold

## Ação

Criação do projeto `financas-semanais` com Vite 6, React 18, TypeScript strict, Tailwind CSS 3, Vitest + React Testing Library, ESLint 9 e Prettier.

## Decisões

- `HashRouter` desde o início para compatibilidade com GitHub Pages.
- `base` do Vite configurável por `VITE_BASE`, com padrão `/financas-semanais/` em build.
- React Router 7 e Zod 4 (versões com correções de segurança) mantendo as APIs usadas.
- Paleta própria inspirada no kit Spendly: creme, verde profundo e lima.
- Cobertura mínima de 90% restrita a `src/domain/`.

## Verificação

- `npm run typecheck`, `npm run lint`, `npm test` e `npm run build` passando.
